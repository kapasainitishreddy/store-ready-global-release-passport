What this prototype checks
The connected demo runs bounded static checks over the included fixture. It does not execute project commands or inspect runtime behavior.
What it does not certify
Compliance obligations depend on the product, data, users, jurisdiction, contracts, and current requirements. This demo does not determine legal compliance or guarantee security.

Not assessed means unknownUnavailable scanners and unsupported profiles never count as a pass.
Local demo data
App names and platform labels are saved in this browser only. No repository URL, credentials, or source files are uploaded.
